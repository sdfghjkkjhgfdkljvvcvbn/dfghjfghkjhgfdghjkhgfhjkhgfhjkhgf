================================================================================
                      COMMON ACTIONS
================================================================================

ADD NEW ITEM:
→ Click "Add [Item]" or "New [Item]" button
→ Fill in form fields
→ Click "Save" or "Add" button
→ Item appears in list

EDIT ITEM:
→ Click "Edit" button on item card
→ Update form fields
→ Click "Update" button
→ Changes saved

DELETE ITEM:
→ Click "Delete" button on item card
→ Confirm deletion in popup
→ Item removed from list

FILTER/SEARCH:
→ Use category buttons to filter (Gallery, Services)
→ Results update instantly
→ No page reload needed

================================================================================
                      COLOR & STATUS CODES
================================================================================

BADGE COLORS:
🔴 Red background    - Primary action, categories
🟢 Green background  - Active, Published status
🟡 Yellow background - Draft, Inactive status
🔵 Blue background   - Before/After indicator
⚪ Gray background   - Secondary actions

STATUS MEANINGS:
✅ Published / Active  - Visible on website
📝 Draft              - Saved but not published
⏱️ Scheduled          - Will publish at set time
❌ Inactive           - Hidden from website

================================================================================
                      HELPFUL TIPS
================================================================================

1. ALL MODULES WORK TOGETHER
   - Projects link to services
   - Services have packages
   - Blog posts can reference projects
   - Gallery images organized by room type

2. CATEGORY CONSISTENCY
   - Use same categories across modules
   - Helps with filtering and organization
   - Makes website navigation cleaner

3. STATUS MANAGEMENT
   - Use Draft for work-in-progress
   - Published for live website items
   - Scheduled for future content

4. MEDIA URLS
   - Projects support Google Drive and direct video links
   - Gallery works with image URLs
   - Hero slider uses background images

5. RESPONSIVE DESIGN
   - All modules work on mobile
   - Tap to edit/delete on mobile
   - Full functionality on all devices

================================================================================
                      TROUBLESHOOTING
================================================================================

MODULE NOT LOADING?
→ Refresh page (Ctrl+R)
→ Check browser console (F12)
→ Restart dev server (npm run dev)

FORM NOT SUBMITTING?
→ Check for red error messages
→ Fill in all required fields (marked with *)
→ Ensure URLs are valid for media fields

DATA NOT SAVING?
→ Current version stores locally only
→ Data will reset on page refresh
→ Phase 2 adds database persistence

STYLING LOOKS WRONG?
→ Clear browser cache (Ctrl+Shift+Delete)
→ Rebuild project (npm run build)
→ Try different browser
